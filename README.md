## Overview
This project focuses on autonomous mapping and path planning using ROS 2. It enables robots to map their environments and plan optimal paths for navigation in real-time, ensuring safe and efficient movement.

## Features
- **Mapping**: Creating a map of the environment using sensors.
- **Path Planning**: Determining the best path for the robot to follow.
- **ROS 2 Integration**: Leveraging ROS 2 tools and algorithms for autonomous navigation.

## Installation

### Prerequisites
- ROS 2 (e.g., Foxy, Humble)
- Ubuntu 20.04 or 22.04 (recommended for ROS 2)
