
## Project Directory Structure

This directory structure is continuously updated as the project progresses. 

```bash
📂 mapping-path-planning-ros2/
├── 📂 docs/                   # Documentation files
│   ├── installation.md        # Installation guide
│   ├── project_plan.md        # Project plan
│   ├── deliverables.md        # Deliverables
│   ├── 📂 reports/            # Reports directory
│   │   ├── final_report.pdf    # Final project report
│   ├── 📂 presentations/      # Presentations directory
│   │   ├── slides.pdf         # Presentation slides
├── 📂 resources/              # Shared resources
│   ├── 📂 images/             # Images for documentation
│   ├── 📂 config/             # Configuration files (e.g., SLAM, navigation settings)
│   ├── 📂 datasets/           # Sample datasets or prebuilt maps (if applicable)
├── 📂 results/                # Test outputs
│   ├── 📂 maps/               # SLAM-generated maps
│   ├── 📂 metrics/            # Performance metrics (e.g., CSV, JSON)
│   ├── 📂 logs/               # ROS or simulation logs
├── 📂 simulations/            # Gazebo simulation-related files
│   ├── 📂 worlds/             # Gazebo world files (.world)
│   ├── 📂 models/             # Custom Gazebo models (optional)
│   ├── 📂 launch/             # ROS 2 launch files for simulations
├── 📂 src/                    # ROS 2 source code packages
├── README.md                  # Main project documentation
├── LICENSE                    # License file
├── .gitignore                 # Git ignore file

```
