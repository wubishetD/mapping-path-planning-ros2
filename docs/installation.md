# Installation and Setup Guide

This guide explains how to set up the environment for running the **Mapping and Path Planning in Autonomous Navigation with ROS 2** project. It covers setting up the ROS 2 workspace, required dependencies, and running the simulation.

---

## Prerequisites
- **Operating System**: Ubuntu 20.04
- **ROS 2 Distribution**: Foxy or Galactic
- **Simulation Tools**: Gazebo, RViz
- **Robot Model**: TurtleBot3

Before proceeding, ensure that ROS 2 is installed on your system. If not, follow the [official ROS 2 installation guide](https://docs.ros.org/en/foxy/Installation.html).
